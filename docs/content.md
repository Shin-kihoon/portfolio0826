# 콘텐츠 정의서 (단계 1 산출물)

포트폴리오 사이트에 들어가는 모든 텍스트를 한곳에 모은 문서.
실제 렌더링되는 값은 `src/data/siteContent.ts` 와 `src/data/portfolioData.ts` 에 있고,
이 문서는 **무엇을 왜 말하는지**와 **아직 확정되지 않은 항목**을 추적한다.

- 표기 `[확인 필요]` — 사실 확인 전이라 사이트에 넣지 않았거나, 값이 비어 있는 항목
- 모든 수치는 실제 분석 결과·커밋 기록과 일치해야 한다. 확인할 수 없으면 쓰지 않는다.
